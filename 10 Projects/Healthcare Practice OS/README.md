# Healthcare Practice OS — project folder

Working container for David's healthcare-software venture: an AI-first, multi-user system for
healthcare centres that connects to the Belgian institutional rails and runs the practice.

**`Healthcare Practice OS` is a placeholder name.** Brand and identity are an open decision; rename this
folder when that is settled.

## What is and is not here

| | |
|---|---|
| **Here** | Project tracking, discovery research (once admissible), decisions, open questions |
| **Not here** | Industry/domain knowledge — that is public reference material in [[30 Resources/Belgian Healthcare & eHealth/README\|Belgian Healthcare & eHealth]] |
| **Not here** | Anything confidential to a current or former employer or counterparty, including contract terms (`data-policy.md` §2.1, §6) |
| **Not here** | Patient data or third-party health data in any form (§2.4) |

Created 1 October 2026 to hold research scaffolding. It deliberately contains **no venture strategy
content** (positioning, pricing, ICP, targets, roadmap) — none has been approved into the vault, and
David's own strategy notes remain outside it.
