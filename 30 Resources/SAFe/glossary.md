# Glossary

The acronym decoder plus the **5.1 → 6.0 rename table**, which matters because client organisations
mix vocabularies. Entries marked *(to verify)* are not yet confirmed against primary sources.

## 5.1 → 6.0 renames and retirements

| 5.1 term (toolkits) | 6.0 term | Note |
|---|---|---|
| Program Increment (PI) | **Planning Interval (PI)** | Same acronym, same cadence |
| Program (level) | **ART** / "team of teams" | "Program" retired as a term |
| Program Backlog | **ART Backlog** | |
| Program Kanban | **ART Kanban** | |
| Program Board | **ART Planning Board** | |
| Program Predictability Measure | **ART predictability** / **flow predictability** | Now one of the six flow metrics |
| Program PI Objectives | **ART PI Objectives** | |
| Scrum Master | **Scrum Master / Team Coach (SM/TC)** | Applies to Kanban teams too |
| Scrum of Scrums | **Coach Sync** (part of ART Sync) | |
| PO Sync + SoS (optional merge into ART Sync) | **ART Sync** (Coach Sync + PO Sync) as the standard name | |
| Core values: Alignment, Built-in Quality, Transparency, Program Execution | **Alignment, Transparency, Respect for People, Relentless Improvement** | |
| Principle #6: Visualise and limit WIP, reduce batch sizes, manage queue lengths | **Make value flow without interruptions** | Plus the 8 flow accelerators |
| Portfolio Kanban "Portfolio Backlog" state; "MVP / Persevere" sub-states | **Ready**; Implementing (MVP → persevere) | |
| Velocity-centric metrics | **Outcomes / Flow / Competency** measurement domains | |
| Strategic themes (statements) | **Strategic themes as OKRs** | OKRs in the spanning palette |
| Seven core competencies (top-level structure) | **[2024+] Five SAFe Disciplines** with competencies | LPM; Team and Technical Agility; Product Development Flow; Large Solution Integration and Delivery; Leadership and Culture |
| Four configurations on the Big Picture | **[2024+]** removed from the main Big Picture | Still the common sizing vocabulary |

## [AI-Native] terms (June 2026)

Full detail and source tiers: [[ai-native-safe]]. [A] = Scaled Agile primary, [B] = SAFe partner, [C] = secondary.

| Term | Meaning | Tier |
|---|---|---|
| **AI-Native SAFe** | Scaled Agile's second operating model for the AI era. Coexists with Core SAFe and builds on it | A |
| **AI-Empowered Agility** | Ability to develop and responsibly deploy AI products quickly while using AI to improve Lean-Agile methods | A |
| **Four Lean-Agile shifts** | Outcomes → outcomes and intent; iterative learning → rapid experimentation; development at scale → development and innovation at scale; cross-functional → AI-augmented teams | A |
| **AI Value Architect** | New role: coaches AI adoption, unlocks value from existing AI tools, bridges business/tech (risk, legal, data, ethics), facilitates AI solution development, optimises outcomes | A |
| **Product / Builder / Domain expert / AI** | The four capabilities that make up an AI-Native team (instead of fixed roles) | A |
| **Align – Sense – Respond** | Team workflow cycle | A |
| **PI / ART / Team Outcomes** | OKR-based outcome hierarchy replacing feature-centric steering | A |
| **PI Outcome Planning** (+ **PI Outcome Planning Board**) | One-day event replacing two-day PI Planning; outcome breakouts then team breakouts | A |
| **ART Sense and Respond** | 2-hour RTE-facilitated event every iteration replacing I&A; manages variability, discards ineffective work | A |
| **Customer Demos** | Regular demos with customers, chosen by purpose (learning/persuasion) and reach | A (B: replaces System Demo) |
| **CIDP** | Continuous Innovation and Delivery Pipeline: the CDP extended from discovery to go-to-market | A |
| **AI innovation pipeline** | AI-empowered workflows + embedded policies + insights and evidence + shared platforms | A |
| **Intent / Specifications / Context** | The information stack agents need: why / what-how / where | A |
| **Curated data** | Complete, accurate, maintained, securely accessed data, built on the runway ahead of need | A |
| **AI governance and ethics pillars** | Controlling AI spend (token limits); enforcing responsible AI; monitoring agentic behaviours; managing and exploiting AI risk | A |
| **12 critical success factors** | Three per shift; used in "Launching AI-Native ARTs" (AI-Native ART Leader certification) | B |
| **AI Council / AI Center of Excellence** | Corporate AI policy body / shared AI practice hub (roadmap phase 5) | C |
| **Intent declaration · Action-boundary specification · Outcome tree · Moonshot/roofshot** | Secondary vocabulary, not confirmed as official SAFe terms | C |
| **Five AI value patterns** | Knowledge and decision support; customer interaction; workforce automation; risk and control; expert productivity | C (B corroborates) |
