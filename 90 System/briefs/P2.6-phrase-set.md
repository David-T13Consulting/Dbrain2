**Expected values:** an ISO date; `RANGE a..b` (a labelled range is the right answer); `UNCLEAR` (the phone asks again, which is correct for this phrase); `NONE` (no date intent: the question passes unchanged, and must **not** ask again). **Scoring:** *silently wrong* = a different date than expected with no label, or a date where `NONE`/`UNCLEAR` is expected and no ask-again. **Target: 0 silently wrong.** `UNCLEAR` where a date was expected is a miss but not wrong; `UNCLEAR` where `NONE` is expected is a regression (the Q72 cost).
